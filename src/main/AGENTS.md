# src/main

## Overview

The Maven main source set: Java code in `java` and runtime resources in `resources`.

## Subdirectories & Boundaries

- java: [./java/AGENTS.md](./java/AGENTS.md) - The Spring Boot app.
- resources - `application.yml` and the Thymeleaf templates. It has no contract of its own because it holds no source code. [The repo blueprint](../../AGENTS.md) covers it.
